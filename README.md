# Job Matcher

Upload your resume in Arabic or English and get the 20 best-fit Summer 2027 internships, flagged for U.S. citizenship and sponsorship limits.

**Status:** in progress. Step 1 of 19.

## Run it locally

    python3.12 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    pytest && ruff check .

See [SPEC.md](SPEC.md) for what's being built and how success is measured.
